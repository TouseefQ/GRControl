# 5.1 Geometric Calibration
Geometric calibration establishes the correspondence between the angular values reported by the instrument's control software and the true physical angles of the LED arc and camera arc relative to the sample plane and the shared vertical rotation axis. This section defines the calibration targets and reference fixtures used (Section 5.1.1), the procedure for establishing each arc's true zero-angle reference (Section 5.1.2), the procedure for verifying angular accuracy across the full sweep range (Section 5.1.3), the procedure for verifying that both arcs' effective rotation axes coincide with the intended common axis (Section 5.1.4), and the procedure for characterizing the sample-side measurement spot position and size (Section 5.1.5). None of the procedures in this section require a human skin sample; all can be performed using passive optical/mechanical reference fixtures, and should therefore be completed before any skin measurement campaign begins, directly supporting Functional Requirements F3, F5, and F8 (Section 4.1.1) and the performance targets defined in Table 4.1.
## 5.1.1 Calibration Targets and Reference Fixtures
Three categories of passive reference fixture are required for the procedures in this section:

- **An optical alignment target** — a small, high-contrast crosshair or fiducial marker (e.g., a printed reticle or a fine-tipped laser pointer mounted on a temporary jig) placed at the intended sample aperture position, used to verify that both arcs' effective centers of rotation intersect at the same physical point above the base plate.
- **An angular reference standard** — an independent, high-precision angle-measurement device (e.g., a digital protractor, a rotary calibration stage, or a second, independently calibrated absolute encoder mounted temporarily on each arc) used to verify the true physical angle of each arc against the value reported by its onboard AS5600/OME85 encoder.
- **A flat, non-specular calibration coupon** — a small flat sample (e.g., a piece of matte white card or a diffuse reflectance standard, distinct from the photometric reference panel used in Section 5.2) placed at the sample aperture, used together with the camera's live preview to verify that the illuminated spot and the camera's field of view remain co-located as each arc rotates.
## 5.1.2 Zero-Angle Reference Establishment
Each arc's absolute encoder (the OME85 for the camera arc, AS5600 #3 for the LED arc, per Section 4.5.2.1–4.5.2.2) reports an angle relative to an arbitrary internal reference determined by the physical orientation of its magnet or ring scale at the time of installation, not automatically relative to the sample's surface normal. Establishing a true zero-angle reference therefore requires manually rotating each arc, using the optical alignment target (Section 5.1.1), to the physical position corresponding to normal incidence/observation (0° from the sample-plane normal), and recording the corresponding raw encoder value at that position as the software home offset (`homeCamera`, `homeLed`, per Section 4.6.1.4/4.7.1.4). This offset is then stored in the ESP32-S3's non-volatile storage, so that all subsequently reported angles are expressed relative to the true sample-normal direction rather than the encoder's arbitrary internal zero. This procedure should be repeated at least three times, remounting and re-zeroing each arc between repetitions, to establish the repeatability of the zero-reference procedure itself, which sets a lower bound on the overall system's achievable angular accuracy independent of encoder resolution.
## 5.1.3 Angular Accuracy Verification Across the Sweep Range
With the zero-angle reference established, the accuracy of the reported angle must be verified not only at the zero position but across the full commanded sweep range of each arc, since backlash, belt-thickness effects (Section 8.5, mechanical/motor-control improvements), and any residual eccentricity in the arc's rotation could cause the relationship between commanded angle and true physical angle to deviate from linearity at larger angles. This is done by commanding each arc to a series of angular positions spanning its full range — for the LED arc, the discrete slit positions from 0° to 60° (Section 4.3.1.1); for the camera arc, the discrete slit positions from 20° to 55° (Section 4.3.2.1) — and, at each commanded position, independently measuring the arc's true physical angle using the angular reference standard (Section 5.1.1), then recording the difference between the commanded/reported angle and the independently measured true angle.

The resulting deviation values, plotted against commanded angle, characterize the system's angular accuracy across its operating range and should be compared directly against the performance targets already established in Table 4.1 — specifically, the OME85's ±0.1° maximum static angular error and ±2 LSB repeatability error for the camera arc. If a systematic (rather than random) deviation pattern is observed — for example, a deviation that grows monotonically with commanded angle — this would indicate a residual mechanical effect (such as the belt-thickness-induced gear-ratio error discussed in Section 8.5) not yet fully corrected by the closed-loop encoder feedback (Section 4.6.1.3/4.7.1.3), and should be documented as a known systematic bias for later measurements rather than left unexplained.
## 5.1.4 Shared-Axis Alignment Verification
Because the LED arc and camera arc are designed to rotate about a single shared vertical axis (Section 4.4.2.3, 4.5.2.3), any physical misalignment between the two arcs' actual centers of rotation — for example, due to accumulated tolerance in the bearing stack (Section 4.4.2.3) or slight eccentricity in the LED rod or camera-arc gear — would cause the illuminated point on the sample and the point observed by the camera to shift relative to one another as either arc rotates, undermining the basic assumption that both angles are defined relative to a single, fixed measurement point (Functional Requirement F1, Section 4.1.1).

This is verified using the optical alignment target and the flat calibration coupon (Section 5.1.1): with the alignment target fixed at the intended sample position, each arc is rotated in turn through its full angular range while observing, via the camera's live MJPEG preview (Section 4.7.2.1) or an external camera, whether the LED's illumination spot (for the LED arc) or the camera's centered field of view (for the camera arc) remains fixed on the alignment target throughout the sweep. Any observed drift of the illuminated spot or the camera's aim point away from the fixed target, as a function of arc angle, quantifies the shared-axis alignment error and should be recorded as a spatial deviation (in millimeters, at the sample plane) as a function of angle for both arcs.
## 5.1.5 Sample Spot Size and Position Characterization
The size and position of the illuminated spot and the camera's effective field of view at the sample aperture directly determine the instrument's angular specificity when measuring a spatially non-uniform sample such as skin (Section 2.2.2), since a detector observing too large an area may collect light that entered the material at one point and re-emerged elsewhere. Using the flat calibration coupon placed at the sample aperture and the camera's live preview, the illuminated spot diameter for each active LED position (Section 4.3.1.1) and the camera's field-of-view diameter for each camera slit position (Section 4.3.2.1) should be measured directly from calibration images, using a scale reference (e.g., a ruler or a printed grid) placed in the same plane as the calibration coupon. This measurement should be repeated across the full range of LED and camera angular positions, since the effective illuminated-spot size and field-of-view diameter both change with angle due to the projected-area (cosine) effect described in Section 2.3, and both results should be tabulated as a function of angle for reference during later measurement-protocol design (Chapter 7).
## 5.1.6 Geometric Calibration Summary
| Procedure | Reference fixture used | Output |
|---|---|---|
| Zero-angle reference establishment | Optical alignment target | Home offset per arc (`homeCamera`, `homeLed`) |
| Angular accuracy verification | Independent angular reference standard | Commanded-vs-true angle deviation curve, per arc |
| Shared-axis alignment verification | Optical alignment target + flat coupon | Spatial drift of illuminated/observed point vs. angle |
| Sample spot size/position characterization | Flat coupon + scale reference | Illuminated spot diameter and FOV diameter vs. angle |

Completing all four procedures in this section produces a fully characterized angular and spatial geometric calibration record for the instrument, which is a necessary prerequisite for the photometric calibration (Section 5.2) and mechanical performance testing (Section 5.4) that follow, and for the reference-material validation campaign (Chapter 6) that should precede any measurement of living human skin.
